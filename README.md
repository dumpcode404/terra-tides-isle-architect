TERRACOTTA TIDES: ISLE ARCHITECT — a cozy 2.5D isometric tile-laying tactics puzzler. Draft tiles, rotate river edges, match biomes, link harbors, bloom forests and trigger ×5 cascades across 3 hand-crafted chapters plus endless mode. Pure Canvas + WebAudio, zero network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Hover or tap any open diamond tile, preview synergy arcs, click to place. Arrows/WASD cursor, Q/E rotate, Space place, Z undo, H hint, 1/2/3 hand tiles, P pause, M mute, R restart. Touch supported.
